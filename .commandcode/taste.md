# Rattle design decisions

- Dark felt-table surface (charcoal warm-tinted), ivory dice faces, single
  amber accent for primary actions and results. No generic tech blue/cyan.
- Product register: dice stage is the working field, tray is the operate
  surface, settings live in a right rail panel.
- One system sans stack; tabular numerals for results.
- Motion: animate transform and opacity only; full/minimal/none modes;
  prefers-reduced-motion support.
- Vanilla HTML/CSS/JS, no build step, GitHub Pages ready.
